# JIKJI AI Landing Page

직지 홈페이지 프로젝트입니다.
A modern, responsive, multilingual landing page for JIKJI AI.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## 로컬 빌드 확인

```bash
npm run build
npx serve out
```

접속: http://localhost:3000

## 배포

GitHub Pages를 통해 자동으로 배포됩니다.

`main` 브랜치에 코드가 push되면 GitHub Actions 워크플로우가 자동으로 실행되어 Next.js 정적 빌드 후 GitHub Pages로 배포됩니다.
