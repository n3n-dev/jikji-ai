---
title: 조직 생성
description: 개인 계정을 조직 계정으로 전환하고 조직을 생성하는 방법
---

## 1. Organizations 메뉴 진입

좌측 메뉴에서 ① **Organizations**를 클릭합니다.

![Organizations 메뉴 진입](/docs/organization-creation/organizations-menu.png)

## 2. 조직 계정 전환 시작

**Organizations** 페이지에서 ① **Convert to Organization Account**를 클릭합니다.

![조직 계정 전환 시작](/docs/organization-creation/organization-switch-start.png)

## 3. 조직 이름 입력 및 전환 실행

팝업에서 ① **Organization Name**을 입력하고 ② 조직 계정 전환에 대한 안내를 확인한 후 동의 여부를 선택한 뒤 ③ **Convert**를 클릭합니다.

![조직 이름 입력 및 전환 동의](/docs/organization-creation/organization-name-and-switch-consent.png)

## 4. 조직 계정 생성 확인

좌측 메뉴에서 ① **Organizations**가 선택된 상태인지 확인하고,
우측 상단 **Switch Account** 메뉴에서 ② 생성한 조직 계정이 추가되었는지 확인합니다.

![조직 계정 생성 확인](/docs/organization-creation/organization-created.png)

## 5. 조직 계정 페이지 확인

생성한 조직 계정을 선택한 후 **Organizations** 페이지에서 ① 우측 상단 계정 정보가 조직 계정으로 표시되는지 확인합니다.

![조직 계정 페이지 확인](/docs/organization-creation/organization-account-page.png)

## 6. GPU 자원 할당 요청

조직 생성이 완료되면 담당자에게 GPU 자원 할당을 요청합니다.

<Callout type="info">
  조직 생성만으로 GPU 자원이 자동 할당되지는 않습니다. 담당자 확인 후 GPU 자원이 할당됩니다.
</Callout>
