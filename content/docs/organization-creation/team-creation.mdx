---
title: 팀 생성
description: 조직 계정에서 새 팀을 생성하고 `team_admin` 초대 링크를 확인하는 방법
---

## 1. 새 팀 생성 시작

조직 계정의 **Organizations** 페이지에서 ① **Create New Team** 버튼을 클릭합니다.

![새 팀 생성 시작](/docs/organization-creation/team-creation-start.png)

## 2. 팀 이름 입력 및 생성

모달에서 ① 팀 이름을 입력한 후 ② **Create Team** 버튼을 클릭합니다.

![팀 이름 입력 및 생성](/docs/organization-creation/team-name-and-create.png)

## 3. 팀 생성 및 초대 링크 확인

<DocNote note="1" description="조직 계정 안에 생성된 팀과 팀별 정보가 표시되는 목록 영역입니다."><strong>Teams(Optional)</strong></DocNote> 목록에서 ① 생성한 팀이 표시되는지 확인한 후, <DocNote note="2" description="각 팀의 초대 링크가 표시되는 영역입니다. 팀 생성 모달의 안내 문구에서는 `Active invitation Links`라고도 표시되지만, 실제 조직 페이지의 영역 제목은 `Invitation Links`입니다. 이 문서에서는 사용자가 화면에서 직접 확인하는 영역 제목인 `Invitation Links`로 통일합니다."><strong>Invitation Links</strong></DocNote> 영역에서 ② 해당 팀의 `team_admin` 초대 링크가 생성되었는지 확인하고, ③ 복사 아이콘으로 링크를 복사합니다.

![팀 생성 및 초대 링크 확인](/docs/organization-creation/team-created-and-invite-link.png)

<Callout type="info">
  `team_admin` 초대 링크는 팀 생성 후 최초 3일 동안만 등록할 수 있습니다.
</Callout>
