jikjicloud.io 문서를 처음 보거나 새로 문서를 작성하는 경우, 아래 용어 기준을 먼저 확인하면 화면 문구와 문서 설명을 더 쉽게 이해할 수 있습니다.

<Callout type="info">
  이 문서에서는 사용자가 직접 생성하고 확인하는 실행 리소스를 기본적으로 `파드`로 통일해 설명합니다. UI나 시스템 문구의 `instance`는 이 가이드에서 파드와 같은 관리 단위로 설명하고, `container`는 파드 안 실행 환경이나 외부 접속 설명 문맥에서 사용합니다.
</Callout>

## 1. 실행 리소스 용어

- **파드(Pod)**: 사용자가 실제로 생성, 확인, 삭제하는 기본 실행 리소스입니다. **GPU Pods** 목록에서 보이는 대상도 파드입니다.
- **Pods / GPU Pods**: 좌측 메뉴 이름은 **Pods**이고, 이동 후 파드 목록 화면 제목은 **GPU Pods**로 표시됩니다. 둘 다 파드 관련 기능과 목록을 가리키는 표현이며, 파드 상태, **Subdomain**, 접속 메뉴도 이 화면에서 확인합니다.
- **컨테이너(Container)**: 현재 가이드 문서에서는 파드 안에서 실행되는 환경이나 외부 접속 설명 문맥에서 쓰는 표현입니다. 사용자가 목록에서 직접 생성하고 관리하는 단위는 컨테이너가 아니라 파드입니다.
- **인스턴스(Instance)**: 일부 UI나 시스템 문구에서 파드를 가리키는 표현입니다. 이 가이드에서는 파드와 같은 관리 단위로 설명합니다.

## 2. 계정, 조직 및 자원 용어

- **개인 계정**: 사용자가 처음 로그인했을 때의 기본 계정입니다.
- **Organizations**: 조직 계정 생성과 팀, 멤버, 자원 관리를 여는 메뉴 및 화면 이름입니다.
- **조직 계정(Organization)**: 팀과 자원을 함께 관리하기 위해 개인 계정을 전환해 사용하는 계정 단위입니다.
- **팀(Team)**: 조직 계정 안에서 멤버와 GPU 자원을 나누어 관리하는 하위 단위입니다.
- `org_admin`: 조직 전체 설정, 팀, 멤버, 자원 배정을 관리하는 권한입니다.
- `team_admin`: 자신이 속한 팀의 운영과 팀원 관리를 담당하는 권한입니다.
- `developer`: 할당된 자원 범위 안에서 파드를 사용하고 작업하는 일반 개발자 권한입니다.
- `viewer`: 조직 정보를 열람하는 읽기 전용 권한입니다. 멤버 초대 문서 기준으로 `org_admin`과 동일한 범위를 열람할 수 있습니다.
- **GPU 자원**: 파드를 생성하고 실행할 수 있도록 조직 또는 팀에 배정되는 자원입니다. 조직 생성만으로 자동 할당되지는 않으며, 담당자 확인 후 조직에 할당될 수 있습니다.

## 3. 저장소 및 네트워크 용어

- **Storage / Filesystem**: 파드에서 연결해 사용할 수 있는 파일 저장소입니다. 문서에서는 메뉴 이름이 필요할 때는 **Storage**, 실제 생성 리소스를 말할 때는 파일시스템으로 설명합니다.
- **Identifier/Subdomain**: 파일시스템 생성 시 이름을 입력하는 필드입니다. 스토리지 생성 팝업에서 보이는 파일시스템 식별자입니다.
- **Region**: 리소스가 배치되는 위치를 나타내는 표기입니다. 현재 가이드 문서 기준으로 스토리지 생성 팝업과 **Filesystems** 목록, 파드 생성 화면에서 모두 **Region**으로 표시됩니다.
- **Firewall**: 외부에서 접근할 수 있는 포트를 관리하는 기능입니다.
- **Inbound Rule**: 외부에서 들어오는 연결을 허용하는 방화벽 규칙입니다.
- **Port Range**: 외부에 열 포트 번호 또는 포트 범위입니다. 예를 들어 `8000` 또는 `8000-8099`처럼 입력합니다.
- **Subdomain**: 현재 문서에는 두 맥락의 `Subdomain` 표기가 있습니다. **GPU Pods** 목록의 **Subdomain** 열은 파드 외부 접속에 사용하는 식별자이고, 스토리지 생성 팝업의 `Identifier/Subdomain`은 파일시스템 이름 입력 필드에 포함된 표기입니다.
- **ICMP**: 네트워크 진단에 사용하는 프로토콜입니다. 방화벽 문서에서는 **Allow ICMP traffic (ping)** 항목으로 표시됩니다.

## 4. 문서 읽기 기준

- 문서에서 리소스 생성, 확인, 삭제 대상을 설명할 때는 `파드`를 기본 용어로 봅니다.
- UI 라벨이 영어로 표시되면 문서도 해당 버튼, 메뉴, 필드 이름은 원문을 유지합니다.
- 같은 대상에 여러 표현이 보이면 이 문서의 정의를 우선 기준으로 해석합니다.
- 화면별 메뉴, 상태값, 컬럼 이름 옆의 `[1]` 표시는 누르거나 마우스를 올리면 간단한 설명이 열립니다. 모바일에서는 눌러서 확인할 수 있습니다.
