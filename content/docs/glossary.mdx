jikjicloud.io 문서를 처음 보거나 새로 문서를 작성할 때 아래 용어 기준을 먼저 확인하면 화면 문구를 더 쉽게 이해할 수 있습니다.

<Callout type="info">
  이 문서에서는 사용자가 생성하고 확인하는 실행 리소스를 `파드`로 통일해 설명합니다.
</Callout>

## 1. 계정 및 조직 용어

- **개인 계정**: 사용자가 처음 로그인했을 때 사용하는 기본 계정입니다.
- **조직 계정(Organization)**: 개인 계정을 전환해 사용하는 조직 단위 계정입니다.
- **Switch Account**: 개인 계정과 조직 계정을 전환할 때 사용하는 메뉴입니다.
- **Organizations**: 조직 계정 생성, 팀 관리, 멤버 초대, 자원 관리를 여는 메뉴와 페이지 이름입니다.
- **팀(Team)**: 조직 계정 안에서 멤버와 자원을 나누어 관리하는 단위입니다.
- `org_admin`: 조직 전체 설정, 팀, 멤버, 자원 배정을 관리하는 권한입니다.
- `team_admin`: 자신이 속한 팀의 운영과 팀원 관리를 담당하는 권한입니다.
- `developer`: 할당된 자원 범위 안에서 파드를 사용하는 권한입니다.
- `viewer`: 조직 정보를 열람하는 읽기 전용 권한입니다.
- **GPU 자원**: 파드를 생성하고 실행할 수 있도록 조직 또는 팀에 배정되는 자원입니다.

## 2. 파드 관련 용어

- **파드(Pod)**: 사용자가 생성, 확인, 삭제하는 기본 실행 리소스입니다.
- **Pods / GPU Pods**: 좌측 메뉴 이름은 **Pods**이고, 목록 화면 제목은 **GPU Pods**입니다. 둘 다 파드를 가리킵니다.
- **Subdomain**: **GPU Pods** 목록에서 확인하는 파드 식별자입니다. 외부 접속 주소를 만들 때 사용합니다.

## 3. 저장소 및 네트워크 용어

- **Storage / Filesystem**: 파드에 연결해 사용할 수 있는 파일 저장소입니다. 메뉴 이름은 **Storage**이고, 생성되는 리소스는 파일시스템입니다.
- **Identifier**: 파일시스템 생성 팝업에서 입력하는 파일시스템 이름입니다.
- **Region**: 파드와 파일시스템을 생성할 때 선택하는 위치입니다. 생성 후에는 목록의 **Region** 값으로 확인합니다.
- **Firewall**: 외부에서 접근할 수 있는 포트를 관리하는 기능입니다.
- **Inbound Rule**: 외부에서 들어오는 연결을 허용하는 방화벽 규칙입니다.
- **Port Range**: 외부에 열 포트 번호 또는 포트 범위입니다.
- **ICMP**: 네트워크 진단에 사용하는 프로토콜입니다. 화면에서는 **Allow ICMP traffic (ping)** 항목으로 표시됩니다.

## 4. 문서 읽기 기준

- 문서에서 리소스 생성, 확인, 삭제 대상을 설명할 때는 `파드`를 기본 용어로 봅니다.
- UI 라벨이 영어로 표시되면 문서도 해당 버튼, 메뉴, 필드 이름은 원문을 유지합니다.
- 같은 대상에 여러 표현이 보이면 이 문서의 정의를 우선 기준으로 해석합니다.
- 화면별 메뉴, 상태값, 컬럼 이름 옆의 `[1]` 표시는 누르거나 마우스를 올리면 짧은 설명이 열립니다. 모바일에서는 눌러서 확인할 수 있습니다.
