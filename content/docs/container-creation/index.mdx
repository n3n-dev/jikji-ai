# 파드 생성

## 1. Pods 메뉴 진입 및 생성 시작

① Pods 메뉴에 진입한 후 ② **Deploy**를 클릭해 파드 생성을 시작합니다.

![Pods 메뉴 진입 및 Deploy 클릭](/docs/4-1-1.svg)

## 2. 파드 유형 선택

① 원하는 파드 유형을 선택합니다.

![파드 유형 선택](/docs/4-1-2.svg)

## 3. 파드 이름 및 요금제 선택

① 파드 이름을 입력하고 ② 요금제를 선택합니다.

<Callout type="info">
  요금제를 선택해도 현재 즉시 과금되지는 않습니다.
</Callout>

![파드 이름 및 요금제 선택](/docs/4-1-3.svg)

## 4. 위치 선택

① 위치를 선택합니다.

<Callout type="info">
  현재는 신사만 선택 가능합니다.
</Callout>

![위치 선택](/docs/4-1-4.svg)

## 5. 저장소 설정

① **Skip Filesystem**을 선택하거나 ② 새 저장소를 생성합니다.

<Callout type="warning">
  Skip Filesystem을 선택하면 별도 저장소를 사용하지 않습니다. 이 경우 파드를 삭제하면 파드에서 사용하던 파일도 함께 삭제됩니다.
</Callout>

![저장소 설정](/docs/4-1-5.svg)

## 6. Launch Instance 클릭

설정을 완료한 후 ① **Launch Instance** 버튼을 클릭합니다.

![Launch Instance 클릭](/docs/4-1-6.svg)

## 7. 약관 확인 및 동의

팝업에서 약관 내용을 충분히 확인하고 동의하는 경우에만 ① **I agree to the above**를 클릭합니다.

![약관 확인 및 동의](/docs/4-1-7.svg)

## 8. 생성된 파드 확인

① 파드가 생성되었는지 확인합니다.

![생성된 파드 확인](/docs/4-1-8.svg)
