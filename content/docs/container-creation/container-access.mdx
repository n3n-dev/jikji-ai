---
title: 파드(Pod) 접속
description: 생성된 파드에 접속하는 방법
---

## 1. 케밥 메뉴 선택

**GPU Pods** 목록에서 접속할 파드 행 오른쪽의 ① <DocNote note="1" description="각 파드 행 오른쪽에 있는 케밥 메뉴입니다. 파드 접속 같은 추가 작업을 시작할 때 사용합니다.">케밥 메뉴(⋮)</DocNote>를 선택합니다.

![케밥 메뉴 선택](/docs/container-access/pod-kebab-menu.png)

## 2. Connect 선택

① <DocNote note="2" description="파드 접속을 시작하는 메뉴 항목입니다."><strong>Connect</strong></DocNote>를 선택합니다.

![Connect 선택](/docs/container-access/connect-menu-item.png)

## 3. 접속 방식 선택

**Connect to Pod** 팝업에서 ① <DocNote note="3" description="현재 가이드 문서 기준으로 지원하는 파드 접속 방식입니다. 브라우저에서 VS Code 웹 페이지로 연결됩니다."><strong>VS Code</strong></DocNote>를 선택한 후 ② **Connect**를 클릭합니다.

<Callout type="info">
  Web Shell은 현재 개발 중입니다.
</Callout>

![접속 방식 선택](/docs/container-access/connection-method-selection.png)

## 4. VS Code 웹 페이지 확인

① VS Code 웹 페이지가 표시되는지 확인합니다.

<Callout type="info">
  세션이 만료된 경우 로그인 후 접근할 수 있습니다.
</Callout>

![VS Code 웹 페이지 확인](/docs/container-access/vscode-web-page.png)
