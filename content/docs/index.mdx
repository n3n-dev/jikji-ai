jikjicloud.io를 처음 사용하는 경우 아래 문서를 순서대로 확인하면 계정 생성부터 조직 설정, 파드 생성 및 접속까지 이어서 진행할 수 있습니다. 별도 파일시스템이 필요할 경우에는 스토리지 관리 문서를 함께 참고합니다.

<Callout type="info">
  처음 사용하는 경우 `계정 생성` → `조직 생성` → `파드(Pod) 생성` 순으로 진행하는 것을 권장합니다. 별도 파일시스템을 관리해야 하면 `스토리지 관리` 문서를 함께 참고하세요.
</Callout>
