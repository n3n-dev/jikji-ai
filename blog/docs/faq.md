# FAQ 작성

Ghost 에디터에서 `/toggle` 카드의 제목에 질문, 본문에 답변을 입력한다. 공개 글·페이지에서는 연속된 Toggle 카드가 아코디언 묶음으로 표시된다. FAQ가 아닌 Toggle 카드에도 같은 스타일이 적용된다.

각 묶음은 첫 답변을 펼친다. 다른 질문을 누르면 기존 답변을 접고, 열린 질문을 다시 누르면 모두 접는다. Tab으로 질문을 선택하고 Enter 또는 Space로 여닫을 수 있다.

기존 글은 제목 2(H2)를 `자주 묻는 질문` 또는 `FAQ`로 지정하고, 제목 3(H3)에 질문, 그 아래에 답변 문단을 작성해도 변환된다. 다음 H2에서 FAQ 영역이 끝난다. 질문이 아닌 일반 섹션은 변환하지 않는다.

에디터에서는 원래 카드·제목 모양을 유지하며, 테마 JavaScript가 공개 화면에서 변환한다. JavaScript가 실행되지 않으면 원본 콘텐츠를 유지한다. 목차에는 FAQ 섹션 제목만 표시한다.

스타일: `theme/assets/css/faq.css`. 동작: `theme/assets/js/faq.js`.

## 모바일 검증 (2026-09-14)

Chrome의 320·375·430·768px 뷰포트에서 PR의 CSS/JS를 직접 로드한 검증 페이지를 확인했다. Ghost 기본 카드 스크립트와 함께 실행했다.

- Toggle 카드와 H2/H3 FAQ 변환, 그룹별 첫 항목 펼침, 하나씩 열기, 모두 접기 확인.
- 독립 그룹 상태 유지, 강조 서식·답변 링크·목록 보존, 다음 H2의 일반 본문 유지 확인.
- Enter/Space 조작, 질문 높이 최소 52px, 페이지 가로 넘침 없음, 콘솔 오류 없음 확인.
- 로컬 실제 News 행사 글에서도 FAQ 열기/닫기·공유 복사·목록 이동을 확인했다.

이는 데스크톱 Chrome의 모바일 크기 검증이다. 실제 iOS Safari/Android 기기의 터치·브라우저별 검증은 아직 수행하지 않았다.
